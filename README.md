# ✨ Toko Ganci ✨

Website sederhana untuk jualan gantungan kunci (ganci) ke teman-teman.

## 💡 Tentang Website
Website ini dibuat pakai:
- HTML
- CSS
- JavaScript

Fungsi:
- Menampilkan produk ganci
- Tombol "Pesan" otomatis
- Pesan dikirim lewat email

## 🛍️ Cara Pakai
1. Buka website
2. Pilih ganci yang mau dibeli
3. Klik tombol "Pesan"
4. Isi nama kamu
5. Email akan terbuka otomatis dengan isi pesanan
